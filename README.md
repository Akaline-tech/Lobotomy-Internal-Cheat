# 功能介绍

本文档概览当前项目已经实现的主要功能，便于快速了解菜单结构、运行方式与各模块用途。

## 项目定位

本项目是一个基于 ImGui、DirectX 11、Kiero、MinHook 与 Mono 运行时接口的 Lobotomy Corporation 内部工具。程序通过 DirectX 11 Present Hook 绘制游戏内菜单，并通过 Mono 接口读取或修改游戏运行时对象数据。

## 基础框架

### DirectX 11 叠加层

程序在 DirectX 11 Present 流程中初始化 ImGui，创建渲染目标并绘制前景层内容。叠加层会在画面左上角显示项目标识文字。

### 菜单开关

按下 Insert 键可显示或隐藏菜单。菜单显示时会释放鼠标限制并显示鼠标指针；菜单隐藏时会恢复游戏内鼠标锁定与隐藏状态。

### 中文字体支持

界面默认尝试加载 Windows 的微软雅黑字体，并配置了中文、日文假名及基础拉丁字符范围。如果字体加载失败，则回退到 ImGui 默认字体。

### 控制台日志

后端启动后会创建控制台窗口，输出 Mono 初始化、程序集查找和方法调用等运行状态，便于排查初始化失败或调用异常。

## Mono 数据接入

### Mono 模块等待与初始化

后端线程会等待游戏加载 mono-2.0-bdwgc.dll 或 mono.dll，随后解析 Mono 导出函数，并附加到 Mono Root Domain。

### Assembly-CSharp 识别

初始化完成后会遍历 Mono 程序集，定位 Assembly-CSharp，并从中获取游戏核心类、字段和方法引用。

### 数据轮询

后端循环会定期读取以下运行时数据：

- 当前 LOB 点数
- 当前能源值
- 能源上限
- 异想体列表
- 员工列表

这些数据会同步到界面中显示，并供功能按钮调用。

## 菜单结构

菜单分为四个页签：

- 全局
- 异想体
- 员工
- 杂项

## 全局功能

### 设置 LOB 点数

在全局页签中输入目标数值后，点击“设置LOB点数”会将 MoneyModel 中的 money 字段设置为输入值。

### 设置能源点数

在全局页签中输入目标数值后，点击“设置能源点数”会将 EnergyModel 中的 energy 字段设置为输入值。

### 跳过当天

点击“跳过这一天(full energy)”会把当前能源值设置为能源上限，用于快速达成满能源状态。

### 状态显示

全局页签右侧会显示当前读取到的 LOB 点数、能源值和能源上限。

## 异想体功能

### 自动镇压

异想体页签提供“自动镇压”开关。开启后，后端会周期性检查异想体状态，并对处于出逃状态的异想体调用 Suppressed 方法。

### 异想体列表

界面会遍历当前异想体列表，显示每个异想体的名称。

### 强制突破

每个异想体条目旁提供“突破”按钮。点击后会对对应异想体调用 Escape 方法。

### 强制镇压

每个异想体条目旁提供“镇压”按钮。点击后会对对应异想体调用 Suppressed 方法。

### 注意事项

界面中已经提示：部分异想体在强制突破时可能导致游戏崩溃，例如樱下墓。同一异想体可以重复强制突破，但不建议这样做。

## 员工功能

### 设置员工移动速度

员工页签可以输入移动速度倍率，点击“设置员工移动速度”后会遍历当前员工列表，并修改每个员工对象的 movementMul 字段。

### 员工信息显示

员工页签右侧会遍历当前员工列表，显示员工名称及当前血量。

## 杂项功能

杂项页签目前已经预留界面区域，但尚未放置具体功能项。

## 自定义界面组件

项目实现了自定义 ToggleSwitch 控件，用于更直观地展示开关状态。该控件支持平滑动画、悬停反馈和圆角外观，当前用于“自动镇压”等开关类功能。

## 依赖与集成点

项目中集成或引用了以下组件：

- ImGui：负责菜单与控件绘制
- DirectX 11 后端：负责游戏画面内渲染
- Kiero：负责图形 API Hook 绑定
- MinHook：负责底层 Hook 支持
- Mono 接口：负责访问 Unity/Mono 游戏运行时对象、字段和方法

## 当前限制

- 功能依赖目标游戏的类名、字段名和方法名，游戏版本变化可能导致偏移或字段失效。
- 强制突破、强制镇压等功能直接调用游戏运行时方法，部分对象可能触发异常或崩溃。
- 杂项页签尚未实现具体功能。
- 自动镇压逻辑依赖对异想体状态值的判断，不同版本中状态枚举可能需要调整。
